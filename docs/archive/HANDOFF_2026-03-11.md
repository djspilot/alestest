## Code-locaties die relevant zijn voor tapgaten/verzonken gaten

### Gat-detectie vanuit STEP geometrie

**Bestand:** `manufacturing_pipeline/analysis/step_processing.py`

- **Functie `detect_cylindrical_holes()`** – detecteert cilindrische gaten (`Sheet_HoleRadii`)
- **Functie `detect_shaped_holes()`** – detecteert gaten met niet-circulaire doorsnede (slots, rechthoeken)
- **Lijn ~980** – shaped hole dict bevat nu ook `"perimeter"` veld (exacte wire-meting via OCC `GProp_GProps`)

**Volgende uitbreiding hier:**
- Tapgaten herkennen via `is_threaded` flag (schroefdraad heeft karakteristieke opp. patroon of apart feature type in STEP)
- Verzonken gaten: kegeloppervlak detecteren (conische face naast cilindrische face)

### Omtrek/straal naar XML

**Bestand:** `manufacturing_pipeline/analysis/cut_features.py`

- **Lijn ~203** – omtrek van shaped holes: pakt `shaped.get("perimeter")`, fallback naar dim-berekening
- **Lijn ~217** – slot-formule: `2*(L-W) + pi*W` (capsule geometrie)
- **Lijn ~228** – `hole_radii` bevat ALLEEN circulaire gaten (niet shaped)

**Volgende uitbreiding hier:**
- Nieuw veld `hole_types` toevoegen: lijst van type per gat (`"round"`, `"thread"`, `"countersunk"`, `"slot"`)
- Tapgaat-straal vs draadmaat conversie (M6 = 5mm kern)

### XML velden (exportvelden)

**Bestand:** `manufacturing_pipeline/reporting/xml_exporter.py`

Huidige XML velden per plaat:
```xml
<Sheet_NrHoles>2</Sheet_NrHoles>
<Sheet_HoleContours>21.36_21.36</Sheet_HoleContours>
<Sheet_HoleRadii>3.4_3.4</Sheet_HoleRadii>
```

**Geplande nieuwe velden:**
```xml
<Sheet_HoleTypes>round_round</Sheet_HoleTypes>          <!-- type per gat -->
<Sheet_ThreadedHoles>0</Sheet_ThreadedHoles>             <!-- aantal tapgaten -->
<Sheet_CountersunkHoles>0</Sheet_CountersunkHoles>       <!-- aantal verzonken gaten -->
<Sheet_CountersunkAngles></Sheet_CountersunkAngles>      <!-- hoek per verzonken gat -->
```

## Bekende classificatie beslissingsboom (v3.0)

```
STAP 0: closed_constant_section → profiel (harde signature)   ← hier zit het probleem
STAP 1: face_analysis (planar% > 50%) → plaat
STAP 1B: bent_sheet_detection → plaat  
STAP 1C: thin_plate (dikte < 25mm) → plaat
STAP 2A: solid_beam (elongated + vol_fill > 0.5) → profiel
STAP 2B: SA/V tiebreaker → profiel
STAP 3A: hollow_tube → anders
STAP 3B: variable_thickness → anders
STAP 4: default → anders
```

**Probleem `10001075565_Rev_00`:**
Dit is een dunne rechthoekige plaat (54×37×8mm) maar STAP 0 pikt het op als `closed_constant_section`
omdat de doorsnede over de hoogte constant en gesloten is.

**Diagnose-commando:**
```bash
python debug_bent_criteria.py  # of maak nieuw debug script voor dit item
```

**Fix richting:**
In `_detect_closed_constant_cross_section()` een uitsluitingscriterium toevoegen voor items
waarbij de kleinste dimensie (dikte) kleiner is dan een drempel (bv. < 20mm).
Zie: `assembly_analysis.py` lijn ~995.
