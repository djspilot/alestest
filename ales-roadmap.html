ALES Implementatie Details

1. Windows FreeCAD Detectie

Huidige code heeft macOS paden hardcoded. Voor ALES Windows omgeving:

def find_freecad_windows(): """Auto-detect FreeCAD op Windows.""" paths = [ os.environ.get("FREECAD_PATH"), r"C:\Program Files\FreeCAD 1.0\bin", r"C:\Program Files (x86)\FreeCAD 1.0\bin", ] for path in paths: if path and os.path.exists(os.path.join(path, "python.exe")): return path raise RuntimeError("FreeCAD niet gevonden")

2. ERP Afwijking Vergelijking

Logica voor het vergelijken van pipeline vs SpaceClaim data:

def compare_with_tolerance(pipeline_val, erp_val, tolerance=0.05): """Vergelijk waarden met ±5% tolerantie.""" if erp_val == 0: return pipeline_val == 0 deviation = abs(pipeline_val - erp_val) / erp_val return deviation <= tolerance

3. ALES Deployment Checklist

  • FreeCAD geïnstalleerd op target Windows server
  • ERP bestandsformaten geïdentificeerd (Excel/XML)
  • Sample dataset beschikbaar (5-10 STEP files)
  • SpaceClaim referentie data formaat bekend
  • Windows Server versie & Python versie bevestigd
